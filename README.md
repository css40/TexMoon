# TexMoon 🌙

**TexMoon** es un editor de texto de escritorio moderno, compacto y ultra ligero. Está diseñado para ofrecer una experiencia de escritura fluida, rápida y sin distracciones, enfocado exclusivamente en la creación, lectura y edición limpia de archivos de texto plano sin la carga ni la complejidad de un IDE pesado.

---

## 💡 ¿Cómo funciona?

* **Edición Directa y Ligera:** Permite abrir, modificar y guardar documentos de texto de forma instantánea.
* **Interfaz Minimalista:** Entorno gráfico simplificado que optimiza la productividad del usuario al concentrarse solo en el texto.
* **Uso Portátil:** Diseñado para ejecutarse rápidamente en sistemas Windows sin configuraciones complejas.
